# nursecallsystem
aplikasi nursecall

## 📄 Referensi Rumus Lisensi
Dokumentasi lengkap rumus pembuatan license key (nama pelanggan, ID pelanggan, jumlah bangsal, kunci rahasia) terdapat dalam file **`RUMUS-LISENSI.md`** di root project.

## ▶️ Cara Menjalankan (tanpa 2 terminal)
Aplikasi kini cukup dijalankan dengan **satu perintah** — server API sekaligus
melayani halaman web:

```bat
npm install
npm start          :: build + jalan, buka http://localhost:3001
```

Agar aplikasi tetap hidup walau terminal ditutup / laptop restart, lihat
panduan **`JALANKAN-TANPA-TERMINAL.md`** (double-click `start-app.vbs`,
PM2, atau service Windows via NSSM).
