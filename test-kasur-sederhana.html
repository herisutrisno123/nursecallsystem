🛏️ Test Kasur Sederhana - Tanpa Bantal & Selimut

✅ Perubahan yang Sudah Diterapkan

1. Bantal (Pillow) telah DIHAPUS

2. Selimut (Blanket) dengan motif garis telah DIHAPUS

3. Teks "Bantal" telah DIHAPUS

4. Sekarang hanya ada: Frame Kasur + Matras + Label "TT 1/TT 2"

❌ SEBELUM (Dengan Bantal & Selimut)

⚠️ Ada bantal dan selimut dengan motif garis

✅ SESUDAH (Hanya Kasur Sederhana)

✅ Hanya frame kasur + matras + label "TT 1"

✅ Tidak ada bantal dan selimut

✅ Lebih sederhana dan jelas

📋 Cara Melihat Perubahan di Aplikasi

1. Buka aplikasi NurseCall Monitor

2. Menu Bangsal

3. Klik tombol "👁 Denah" pada card kamar

4. Lihat modal detail kamar

5. Kasur sekarang hanya menampilkan frame + matras + label "TT 1/TT 2"

⚠️ Jika Masih Lihat Bantal & Selimut

Browser cache masih menyimpan file lama!

Solusi 1 - Hard Refresh:

• Windows/Linux: Ctrl + Shift + R

• Mac: Cmd + Shift + R

Solusi 2 - Clear Cache Lengkap:

1. Tekan Ctrl + Shift + Delete

2. Pilih "All time" / "Semua waktu"

3. Centang "Cached images and files"

4. Klik "Clear data"

5. Refresh halaman

Solusi 3 - Incognito Mode:

• Chrome: Ctrl + Shift + N

• Firefox: Ctrl + Shift + P

• Edge: Ctrl + Shift + N
